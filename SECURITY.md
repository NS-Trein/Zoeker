# Beveiliging / Security

Treinplek is een onofficiële app, niet van NS.

**Een beveiligingsprobleem gevonden?** Mail naar treinplek@gmail.com met wat je gevonden hebt en hoe ik het kan nabootsen.
Ik probeer binnen een paar dagen te reageren. Maak geen gegevens van anderen buit en overbelast de dienst niet.

**Found a security issue?** Email treinplek@gmail.com with what you found and how to reproduce it.
I will try to reply within a few days. Please do not access other people's data or overload the service.
